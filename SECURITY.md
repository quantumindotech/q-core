# Security Policy

## Scope

This policy covers security issues in this repository's code, documentation, architecture, and disclosed integration interfaces.

## Reporting

Do not publish exploitable details, credentials, private keys, seed phrases, or personal data in public issues.

Use GitHub's private vulnerability reporting feature if enabled for this repository. If it is unavailable, contact the repository maintainers through a verified private channel. Do not assume that a public issue is a confidential report.

## Handling

Reports should include the affected component and version, impact, reproduction steps, and available evidence. Maintainers should acknowledge, triage, reproduce safely, assign severity, coordinate remediation, and document closure.

## Security claims

No component is guaranteed secure. PQC or quantum readiness is a target design objective unless and until supported by implementation, test results, and appropriate independent cryptographic review.

Never send transactions, expose production credentials, or test third-party infrastructure without explicit authorization and a defined scope.
